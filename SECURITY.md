# Security Policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.

Include the affected version, impact, reproduction steps, and any suggested
mitigation. Do not include live credentials, customer source code, private
contracts, or other personal or confidential data.

## Supported versions

Security fixes target the latest released version of Ionic Essential. Older
versions may receive a fix when the change can be applied safely, but no
support window or response-time commitment is promised for the community
edition.

## Disclosure

Please allow a reasonable period for investigation and remediation before
public disclosure. We will coordinate credit and disclosure timing with the
reporter when practical.
