license materials in its application resources. Look under:

archive and source repository contain dependency manifests that identify the
resolved build inputs. If a packaged notice and a component's license disagree,

3. Bundled Python runtime and Ionic command-line engine

   The Windows desktop package includes a managed Ionic CLI so users do not
   need a separate Python or pip installation. That executable includes or
   depends on the Python runtime, packaging bootloader code, and Python
   libraries. The direct runtime dependency set includes Pydantic, Typer, Rich,
   and PyYAML. Builds that include all Ionic integrations also include the MCP

   The corresponding licenses and required notices for the exact files in the

   license or notice text. Optional integrations remain subject to the terms
   of the external service when the user chooses to connect to that service.

   application's chosen license. The packaged license browser includes the
   exact PyInstaller terms and exception used by this build.

   The Windows Setup EXE is built with NSIS 3.0.4.1 and electron-builder's
   nsis-resources 3.4.1 bundle. The Setup temporarily embeds the following
   separately loaded plug-ins in addition to NSIS core plug-ins:

   - StdUtils 1.14 (FileVersion 1.1.4.0), distributed under
     LGPL-2.1-or-later with the author's NSIS plug-in clarification.
   - Nsis7z 19.00, following the exact 7-Zip 19.00 and LZMA SDK terms:
     LGPL-2.1-or-later plus component-specific terms and public-domain code.
   - UAC 0.2.4c, distributed under the zlib License.

   Exact license texts, binary provenance, upstream URLs, and SHA-256 hashes
   are included in resources/legal/licenses/NSIS-plugins/. Complete
   corresponding source archives are included in
   resources/legal/sources/NSIS-plugins/.

   WinShell 20121005 is not embedded. Its upstream artifact did not provide an
   exact redistribution license beyond the label "Freeware," so Ionic uses
   source-visible NSIS System/COM calls for the equivalent Shell operations.
